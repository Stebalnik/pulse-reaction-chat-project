# Packages

Shared libraries and offline research tooling live here.

- `shared-schemas/`: typed access to versioned contracts in `schemas/`.
- `rppg-engine/`: on-device RGB trace to pulse-rate estimation core.
- `research-pipeline/`: offline ingestion, benchmark, and report tooling for consented datasets.

The rPPG engine accepts already-extracted RGB traces. Camera capture, face tracking, reaction inference, and UI remain separate packages/apps.
