# Apps

Runtime application surfaces live here.

- `browser-client/`: consent-first browser experience for local capture, quality display, and later WebRTC UI.
- `signaling-backend/`: authentication, age-gating, matchmaking, WebRTC signaling, feature flags, and abuse-prevention services.

The browser client now includes a public no-login MVP shell and an internal admin/debug surface. Server-backed accounts, matchmaking, analytics storage, and real signaling remain backend milestones.
